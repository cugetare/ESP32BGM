# ESP32BGM
<img width="800" height="500" alt="image" src="https://github.com/user-attachments/assets/1ae17d7f-0b93-4f5f-8ffe-be9abacf5fd7" />
A project for ESP32 microcontroller that handles background music (BGM) playback and audio processing.

## Features

- BGM playback on ESP32
- Audio file streaming and decoding
- Volume control and audio effects
- Memory-efficient audio processing

## Requirements

- ESP32 development board
- ESP-IDF framework
- Audio codec libraries

## Getting Started

1. Clone the repository
2. Configure ESP-IDF environment
3. Build and flash to ESP32
